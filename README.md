## Purpose / الهدف

**English:**  
This tool recolors the black or near-black text in selected PDF pages to a user-chosen color, enabling students to trace verses directly on printed Quran pages. By highlighting the script in vibrant hues, it aids memorization, improves handwriting practice, and makes recitation exercises more engaging.

**العربية:**  
يُعنى هذا السكربت بتغيير لون الحروف السوداء أو القريبة من الأسود في صفحات محددة من ملف PDF إلى لونٍ يختاره المستخدم، مما يُسهل تتبع الآيات عند طباعتها. من خلال إبراز الخط بألوان زاهية، يساعد ذلك في الحفظ وتحسين مهارات الكتابة وجعل تمارين التلاوة أكثر تفاعلاً.
